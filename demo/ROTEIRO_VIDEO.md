# Roteiro para demonstração

Sugestão de vídeo curto, com duração de até 30 segundos:

1. Abrir o TaskFlow e mostrar a lista e o resumo de progresso.
2. Pesquisar uma tarefa ou selecionar um filtro.
3. Abrir os detalhes de uma tarefa.
4. Marcar a tarefa como concluída e mostrar a mudança de status.
5. Cadastrar uma nova tarefa.

Antes de gravar, execute `npm start` e abra o projeto no Expo Go compatível com a versão do SDK do aplicativo.

Use dados de exemplo e verifique se os textos e toques aparecem com clareza. Se o vídeo fizer parte da entrega, coloque a gravação em `demo/demo.mp4` e execute:

```bash
npm run validar-entrega
```

A validação automática confere o formato e a duração, mas é importante assistir ao vídeo para garantir que a demonstração esteja legível.
